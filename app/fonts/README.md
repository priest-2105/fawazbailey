# Local typefaces

These are the same Latin WOFF2 assets downloaded by Next.js from Google Fonts during development. Keeping the files in the app removes network access from font compilation and preserves the typefaces already used in the portfolio.

- Inter: variable weight, used by the existing portfolio.
- Archivo Black: regular, used by the existing portfolio display headings.
- Manrope: variable weight, used only by `/ecommerce-projects`.

Each family is distributed under the SIL Open Font License. See the accompanying family-specific OFL text files. Sources: Google Fonts repository, `ofl/inter`, `ofl/archivoblack`, and `ofl/manrope`.
